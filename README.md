# Creative Concept Generator

A reusable AI skill for developing original concepts for photoshoots, fashion and art photography, product videos, reels, and brand campaigns.

It takes a brief and optional visual references, then proposes 3–5 concepts with practical direction for lighting, location, styling, movement, framing, and production needs. Character and world-building guide concept development, campaign structure, and image critique.

## Use the skill

Download [creative-concept-generator.skill](creative-concept-generator.skill) to import into a tool that supports `.skill` packages.

For Codex, download this repository and place its contents in a folder named `creative-concept-generator` under your configured skills directory, such as `~/.codex/skills/creative-concept-generator`. Start a new chat if needed for skill discovery.

Example requests:

```text
Use $creative-concept-generator to propose ideas for a repeating product reel that demonstrates my photography and AI coaching.
```

```text
Give me 3–5 concepts for a skincare brand photoshoot. The audience is independent beauty brands, and the format is a vertical campaign series.
```

Include the product or project, audience, goal, format, and any references you have. Incomplete briefs are welcome.
